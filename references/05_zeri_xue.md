# 《协纪辨方书》传统择日学与建除十二神实战指南

> 「吉凶动静，皆由时发。堪舆之术，体在峦头，用在理气，而发机于择日。」——《协纪辨方书》

---

## 一、 择日学核心原则

堪舆学讲究「不得真龙得年月，也应富贵发人家」。即便房屋坐向理气兼善，若在岁破、月破、三煞之期动土开工或乔迁入宅，亦易引发意外困扰。

择日之要，以**避凶**为第一要务，**趋吉**为第二法门：
1. **避大凶**：岁破、月破、年三煞、月三煞、五黄会合、受死日、正四废；
2. **避冲克**：避开冲犯宅主生肖太岁与主事人生辰干支；
3. **趋吉神**：取天德、月德、天德合、月德合、天恩、母仓、开日、成日；
4. **乘生气**：结合玄空飞星年白月白，当令旺星到门到向之吉时。

## 二、 建除十二神（十二建星）吉凶详辨

建除十二神依日月运行流转，以月建地支为起点顺布十二辰：

| 建神 | 吉凶定性 | 宜 | 忌 | 实战白话要诀 |
| :--- | :--- | :--- | :--- | :--- |
| **建** | 平中带凶 | 祭祀、祈福 | 嫁娶、开市、动土修造 | 气势独盛，万物不任，除祭祀外不宜开张动土 |
| **除** | 吉神 | 沐浴、扫舍、求医、去疾 | 嫁娶、出行、安葬 | 除旧布新之期，最利除煞、清扫房屋、大扫除 |
| **满** | 次吉 | 入宅、纳财、宴客、结纳 | 开渠、动土、安葬 | 丰盛圆满之象，利乔迁入宅与收账纳财 |
| **平** | 平日 | 修饰垣墙、平整道路 | 诉讼、嫁娶、重大签约 | 平安平常，平常事务可为，重大动作宜缓 |
| **定** | 吉神 | 签约、安床、祈福、栽种 | 远行、诉讼、词讼 | 安定平稳之日，最利安主卧睡床、长期协议 |
| **执** | 小凶 | 捕猎、筑堤、安防 | 开门、开市、搬家入宅 | 执拗守旧，宜守成，忌开创新局 |
| **破** | **大凶** | 拆旧屋、破土破旧 | 嫁娶、开张、入宅、几乎万事不宜 | 日逢月破，诸吉难化，动土入宅犯之易遭官非病患 |
| **危** | 次凶 | 祭祀、安居 | 登高、涉险、开工动土 | 危惧不安，如履薄冰，只宜安居静守 |
| **成** | **大吉** | **入宅乔迁、开业开张、嫁娶、动土** | 词讼、争执 | 功成名就，百事皆吉，为阳宅开工与乔迁首选吉日 |
| **收** | 次吉 | 收款、纳财、进人口、签单 | 远行、出殡、开渠 | 收获入仓之象，利经商纳财与签定订单 |
| **开** | **大吉** | **开市交易、入宅迎祥、嫁娶、出行** | 破土、安葬 | 阳气大开，生气勃发，百事迎吉之黄道大日 |
| **闭** | 凶 | 修堤封穴、筑室筑墙 | 开业、看病、远行嫁娶 | 天地闭塞，气机不通，忌开工纳气与新张 |

## 三、 四大常见堪舆事项择日规范

### 1. 入宅 / 乔迁（搬新家）
- **吉神宜取**：天德、月德、天德合、月德合、生气、开日、成日、满日。
- **神煞大忌**：
  - 严避**岁破日**（与当年太岁相冲之日）与**月破日**（与当月月建相冲之日）；
  - 严避主事人本命生肖冲克之日（如属马人避子日）；
  - 严避**归忌日**、**受死日**、**往亡日**。
- **进门吉方**：建议宅主携米粮油火，从宅主命卦之**生气方**或玄空当令**九紫向星方**率先迈门而入。

### 2. 开市 / 开业（商业办公）
- **吉神宜取**：天德、月德、天财、开日、成日、定日。
- **避忌要点**：月破、受死日、闭日。开张纳客注重水流与气口，宜选择向首当令旺星方迎客。

### 3. 动土 / 装修修造（破土开工）
- **首重避煞**：
  - **太岁方**：当年太岁所占方位（如甲辰年辰方、乙巳年巳方、丙午年午方）不可先起锤动土。
  - **三煞方**：当年三煞全盘所落卦位（如申子辰年煞南、寅午戌年煞北、亥卯未年煞西、巳酉丑年煞东）。
  - **五黄煞位**：流年五黄飞临之宫（如2026丙午年五黄在东北艮宫）。
- **动土首锤**：宜从全宅吉方（当令吉星或延年、生气位）起锤，最后方可触及煞方。

### 4. 婚嫁嫁娶
- 重男女双方八字命造，避刑冲克害，选成日、开日与红鸾天喜之期。
